# OffshorePlus v0.6

- Live lønn teller bare i planlagte arbeidstimer.
- Live overtid og ventetid kan startes/stoppes fra Tillegg.
- Valgfritt røykdykkertillegg per måned.
- Valgfri redningslag-/høyderedningsøvelse per tur.
- Redningslagøvelsen kan beregnes med ordinær timelønn eller overtidsats.
- Eget felt for annet fast/lokalt tillegg per tur.
- Alle tillegg vises separat i lønnsoversikten.
